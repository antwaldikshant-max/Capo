Set up Capo online

This site runs on Node.js 20 or newer without package installation. The app stores site content and private project inquiries in a JSON file. Use a persistent server disk and an HTTPS reverse proxy for an online deployment.

1. Start the server

The included Docker Compose setup builds the site and keeps data in the capo_data volume. On a Docker host, set a random first-owner token in a private .env file beside docker-compose.yml:

CAPO_SETUP_TOKEN=replace-this-with-a-long-random-secret
# Optional, for email replies from the private inbox:
RESEND_API_KEY=
CAPO_FROM_EMAIL=

Generate a random secret with node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))", then start the app with:

docker compose up --build -d

2. Create your private owner login

After the app is behind HTTPS, visit https://your-domain/admin. Use the setup token to create the owner email and a password of at least 12 characters. Once the account is created, delete CAPO_SETUP_TOKEN from .env and restart with docker compose up -d.

3. Connect email replies (optional)

In Resend, verify a sending domain and create an API key with email sending permission. Set RESEND_API_KEY and CAPO_FROM_EMAIL to that key and your verified sender address, then restart the app. Replies are sent only when the dashboard shows email as ready.

Project inquiries are saved in the inbox without email setup. The server does not email the owner when a new inquiry arrives.

Storage and privacy

Keep /data on a persistent private volume and make regular backups. Run a single app instance against the JSON file. The owner password is stored as a salted hash; inquiry and content records are stored as plain JSON on the server disk. The application does not create HTTPS certificates; use your hosting platform or an HTTPS reverse proxy.

See the README.md file in the project folder for environment variables and the full deployment notes.
